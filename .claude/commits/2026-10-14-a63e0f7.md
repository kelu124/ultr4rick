# python: rename pic0rick -> ultr4rick, match embarke firmware

- **Commit:** a63e0f74bcb48655352d5fae13f3d307cd990f4d (branch embarke-ultr4rick)
- **Date:** 2026-10-14
- **Files:** python/ultr4rick/ (renamed from python/pic0rick/: __init__.py, device.py, dsp.py, ndt_acquisition.py,
  version.yaml), python/example_dsp.py, python/Readme.md, python/example_*.ipynb (sources only),
  python/data/README.md, requirements.txt, .gitignore

## Why
The embarke firmware now identifies as Ultr4rick (USB strings, `U4RK` frame magic). The copied `python/pic0rick`
library expected `P0RK` frames and was missing helpers for the commands the firmware has.

## What changed
- Package dir renamed to `ultr4rick`. Class `Pic0rick` -> `Ultr4rick`, with `Pic0rick` kept as an alias.
- `dsp.MAGIC = b"U4RK"`. New `dsp.parse_fields`, and `dsp.check_selftest` (same nRMS <= 1e-4 metric as
  `firmware/tools/ultr4rick_capture.py`).
- `device`: port auto-detect by USB ID (cafe:4011 DSP, then 2e8a:0009 stdio), then the old glob fallback. New
  `reboot_dfu`, `close`, `command` (OK/ERR reply, raises on ERR), `help`, `set_alaw_reference` (`dsp scale`),
  `selftest`, `stream_start` / `stream_frames` / `stream_stop`.
- `example_dsp.py`: runs the self-test, and arms the pulser only with `--arm`. Notebooks: imports and text only;
  the saved outputs from the old pic0rick run were left untouched.
- Version 0.1.8 -> 0.1.9.
- Repo-root `requirements.txt` (numpy, pyserial, scipy, matplotlib, h5py, jupyter). Root `.gitignore` covers
  `__pycache__`, `.venv`, notebook checkpoints and KiCad `~*.lck` files.
- The notebooks now use a local `python/data/` folder instead of the missing `../docs/data/` (HDF5 cache and
  `dsp_captures/`).
- `example_dsp.ipynb` has a new section 14, "Idle vs pulsed capture". It takes an idle reference, arms, does one
  raw + envelope capture, and disarms in `finally`. It plots full raw / 15 µs zoom / log envelope and saves
  `data/pulsed_capture.png`. The old section 14 (disarm) is now 15.

  serial U4RK0001. `status` shows board=ultr4rick package=RP2350B firmware=0.1.12, pulser disarmed. `help`,
  `dac write 300`, `write mux 0` and `clear mux` all reply OK.
