# data/

Local output folder for the notebooks in `python/`, which are run with `python/` as the working directory.

- `calibration_block_5steps_1018steel.h5`: HDF5 cache written by `example_acquisition.ipynb` (`from_probe`) and
  read by `example_process.ipynb`.
- `dsp_captures/<payload>/`: one-shot raw/envelope/A-law captures from `example_dsp.ipynb`.
- `pulsed_capture.png`: the idle vs. pulsed comparison figure from `example_dsp.ipynb`.
